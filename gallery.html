BIWEEKLY REWARD RULES

      
🏆 作品奖励评审规则与注意事项

      
鼓励同学围绕校园真实场景持续创作可体验的软件作品，由平台每两周统一评审并额外发放 Token 奖励。


      

        
1. 评审周期与奖励档位

        
    
          
  • 评审周期：原则上每两周评审结算一次，由平台管理员按期复核并统一公布获奖名单、发放奖励。
    • 
          
  • 资金来源：奖励 Token 属于平台额外激励，直接入账到作者个人账本，不扣减所在学院/组织的原有额度池。
    • 
        

        

        

      


      

        
2. 评审与排序规则

        
    
          
  • 入围范围：本组织内状态为「已发布」的学生原创软件作品（不含平台内置演示示例，也不含已撤回、已下架作品），且当期至少获得 1 个有效点赞。
    • 
          
  • 有效点赞口径：仅统计本组织内「已准入」成员的去重点赞（每人每作品限 1 票）；作者给自己点赞不计入有效票数。
    • 
          
  • 排序与破平：纯按有效点赞数从高到低排序；有效赞数相同时，按作品发布时间更早者优先。按排名依次授予一、二、三等奖（若当期有效入围作品少于总名额，按实际入围件数发放）。
    • 
          
  • 到账查询：平台确认结算后奖励即时到账，作品广场与详情页将自动点亮 🏆 获奖徽章；作者可在「我的创作 → 我的看板 → Token 使用记录」中查看入账流水。
    • 
        

      


      

        
3. 注意事项

        
    
          
  • 单件作品不重复获奖：每件作品终身仅可获得一次平台榜单奖励，已获奖作品不再参与后续期次的重复评选，鼓励持续创作新作品。
    • 
          
  • 严禁刷票与搬运抄袭：禁止拉小号、互刷、非真实体验刷赞或直接搬运他人作品参评；平台复核发现异常数据有权取消当期获奖资格或下架作品。
    • 
          
  • 保持作品可访问：参评作品需确保托管网页能正常打开，或安装包/访问链接真实有效；结算前若作品已撤回、下架或作者账号被停用/待复核，则不参与当期发奖。
    • 
          
  • 多身份不重复发奖：同一作者若同时拥有校园邮箱与学号等多个登录身份，同一件获奖作品仅向其主账户发放 1 份奖励。
    •
