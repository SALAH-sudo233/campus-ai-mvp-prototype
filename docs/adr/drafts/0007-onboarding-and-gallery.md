# 0007 新手引导与作品广场

状态：草案
日期：2026-11-20

## 背景

新用户需要一条短路径理解团队协作、选择工具、做出第一个作品并进入平台。作品也需要一个本组织内的展示和审核流程。

## 决策

### 四步引导

| 步骤 | 内容 | 完成条件 |
|---|---|---|
| 认识团队 | 介绍总协调、项目规划、任务执行，并附一次内部角色对应说明 | 确认参考分工 |
| 选择工具 | 介绍两种团队产品的定位和通用练习 | 选择产品或“先用演示了解” |
| 做出作品 | 预制校园活动清单，筛选、收藏、改标题 | 完成交互检查并确认 |
| 探索平台 | 选择产品广场或个人信息 | 确认去向并结束 |

四步都可跳过，跳过不计完成。关闭引导记录一次退出。新注册用户自动打开，老用户只在工作台看到提示。

步骤定义来自服务端配置，渲染按 `kind` 处理。新增步骤只改配置和对应内容块，不重写整个渲染流程。

### 进度

进度存服务端 `onboarding_progress`，主键是用户和流程。每次写入带 `expectedRevision`，不匹配返回 409。草稿只接受配置允许的字段，上限 16 KiB。重复提交相同目标状态不增加修订号。

第 3 步首期只接受 `demo` 完成记录。全过程显示“演示”，不调用真实 AI，不扣真实额度。视频素材地址为空时，视频块不渲染。

### 作品

作品状态为 `draft`、`pending_review`、`published`、`rejected`、`withdrawn`、`removed`。学生提交后进入待审核，组织管理员通过后只在本组织可见。作者可以随时撤回。组织管理员可以精选、取消精选和下架，平台管理员可以全局下架。

精选关系保存在 `featured_works`，主键包含组织，不使用全局精选字段。

作品卡只接作品摘要和事件，广场、个人作品和教师精选复用同一份组件。

## 后果

- 引导可跨设备恢复，跳过、完成和退出可以分别统计。
- 演示练习不会被算作真实创作成功。
- 作品审核与精选按组织隔离，平台只做全局下架和审计。
- 真实产品入口、截图和安装步骤不在首期教程内。
