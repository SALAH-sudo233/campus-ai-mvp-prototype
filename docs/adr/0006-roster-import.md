# 0006 名单导入

状态：已接受
日期：2026-11-20

## 背景

试点需要把学校名单放进组织，并让组织管理员自行维护成员。当前没有导入能力，也没有可重复的校验与审计。

## 决策

首期只收 UTF-8 CSV，固定列，先预览后确认。

### 文件

| 项 | 规则 |
|---|---|
| 列 | `external_ref,student_id,email,name,role,status` |
| 编码 | UTF-8，可带 BOM |
| 文件上限 | 10 MB |
| 行数上限 | 10,000 行 |
| 单字段 | 256 字符 |
| 整行 | 4 KB |
| 角色 | `org_admin`、`org_member`，解析层接受“教师”“学生”别名 |
| 状态 | `active`、`disabled` |

学号和邮箱至少填一个，姓名必填。文件内 `external_ref` 和身份不能重复。公式前缀、控制字符、非法引号和非法编码直接拒绝。

### 预览

预览只写 `import_batches` 和 `import_rows`，不写成员表。每行返回 `row_no`、结果、`reason_code` 和脱敏字段。预览批次有 30 分钟有效期，过期后必须重新上传。

### 确认

确认前先校验组织权限，再进入写事务。同一批次重复确认返回原结果，不重复授予、不重复写审计。合法行可以写入，非法行和冲突行保留在结果里。组织管理员提交其他组织编号返回 403，且不解析文件。

### 隐私与上限

错误报告再次鉴权，邮箱和学号脱敏，公式前缀在导出时转义。导入上传有独立的 10 MB 限制，不放宽其他 JSON 接口的 64 KB 上限。

## 后果

- 组织管理员可以自行维护本组织名单，平台管理员可以指定组织导入。
- XLSX 导入需要新的解析依赖和文件安全评审，留到后续。
- 导入结果可重放，审计记录包含批次、操作者、组织和计数，不含密钥或完整敏感字段。
