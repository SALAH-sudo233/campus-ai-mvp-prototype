状态：已生效（2026-11-26 确立「C 端社区创空间 + B 端企业控制台」双层视觉规范）  
适用范围：**浣溪AI Lab** 全部四端（① 学生端、② 学院大盘、③ 校内运营端、④ 平台管理端）

## 1. 背景与双层视觉分层原则

单一 C 端社区圆润卡片风格应用在后台管理场景时会产生信息密度低、留白松散、演示稿观感过重的问题。自 V2.1 起，**浣溪AI Lab** 确立清晰的双层视觉体系（主品牌色 `#624AFF` 与极光青 `#13C2C2` 跨端保持同源）：

1. **C 端学生门户（ModelScope 创空间圆润卡片体系）**：
   - 适用：`① 学生端`（已锁稿 ✓）；`② 学院大盘` 保持单页四段式只读汇报视图（深海靛蓝顶栏 + 图表/热力图/精选成果墙），去除角色说教与功能自嗨解释文案。
   - 特征：纯白 `#FFFFFF` 画布 + 冰云软壳 `#F7F9FD`、`20px–24px` 圆润卡片、极光漫射 Hero、星轨热榜轮播与悬停微倾缩略图卡片。
2. **B 端管理控制台（Enterprise App-Shell + 标准高密度数据表 + 零说明文案）**：
   - 适用：`③ 校内运营端`、`④ 平台管理端`（参考 Linear / Stripe Dashboard / OpenAI Platform 企业级 SaaS 控制台）。
   - 特征：
     - **全屏贴边 App-Shell 骨架**：顶部 `32px` 紧凑环境切换条 + 左侧 `232px` 贴边固定侧栏（`#FAFBFF` 底、`16×16` 线性 SVG 图标、去除序号前缀与权限说教框）+ 右侧吸顶 `56px` 动态面包屑/快捷动作顶栏 + `#F5F7FB` 浅灰蓝高密度滚动工作区。
     - **12px 硬朗面板与标准数据表（Data Table）**：统一使用 `.adm-panel`（`#FFFFFF` 底、`1px solid #E5E8F0`、`12px` 圆角、极轻阴影）与 `<table>` 标准行列展示租户、审批单、风控事件与审计日志；按钮统一收敛为 `8px` 圆角（`rounded-lg`），数字/ID/邮箱/金额强制 `.mono` + `tabular-nums`。
     - **零说明文案准则**：彻底剔除后台界面中的 PRD 解释句、角色职责说教框、渐变发光宣传横幅与功能吹捧副标题，仅保留精准字段名、状态徽章与操作入口。

## 3. 四端信息架构与交互红线

| 端 | 视觉层级与壳形态 | 一级板块（严格 ≤ 4 项） | 专属交互与文案红线 |
| :--- | :--- | :--- | :--- |
| **① 学生端** | C 端创空间（极光登录页 + `60px` 顶栏 3 导航 · 已锁稿 ✓） | `Token 门户` · `学习与挑战` · `作品广场` | 顶栏右侧收敛为单个头像下拉菜单（含 `我的作品` 与 `退出登录`）；`学习与挑战` 提供独立 CMS 实战教程与主题挑战全闭环详情页；严禁出现固定周期榜单概念 |
| **② 学院大盘** | 单页四段式只读数据大盘（极光浅色与沉浸深色投屏双模） | `实训与服务总览` → `赛训归因与梯形漏斗` → `赛道双环/散点象限/产出榜` → `精选种子作品墙` | 严格纯只读、零口号文案、不区分本科/研究生、不暴露底层模型渠道与内部预占账本；全部指标匹配专属交互图表，支持投屏脱敏与数据简报复制 |
| **③ 校内运营端** | B 端 App-Shell（贴边侧栏 + 吸顶面包屑 + 数据表） | `成员与准入` · `作品管理` · `教程管理` · `挑战与激励` | 仅限本院日常运营；挑战与激励采用**学院激励池预算预占制**（总额 = 已发 + 挑战冻结 + 可用余量），零权限说教文案 |
| **④ 平台管理端** | B 端 App-Shell（贴边侧栏 + 吸顶面包屑 + 数据表） | `总览看板` · `合作学院` · `额度与审批` · `风控与审计` | 标准多租户表格管理学院与双账号口令重置；监控各院激励池三态水位；增池审批与密钥冻结均带二次确认弹窗并写入审计日志 |

### 通用技术与交互红线
- 禁止引入 `googleapis` / `gstatic` 等外部阻塞字体外链；
- 禁止使用浏览器原生 `alert()` / `confirm()` / `prompt()`，统一使用非阻塞 `Toast` 与轻量确认弹窗；
- 密钥明文仅在首次生成或重置时单次可见，审计日志严禁记录密钥明文。
