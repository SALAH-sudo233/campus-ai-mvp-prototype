# 0003 UI 与交互设计规范（V1 四端统一版 · 取代 2026-11-20 旧版）

状态：已接受（2026-11-26 由 `@ouyangchao3212-maker` 审批锁定）
适用范围：**浣溪AI Lab** 全部四端（① 学生端、② 学院端、③ 运营管理端·学校用、④ 平台管理端·浣溪内部）

---

## 1. 背景与升级目标

2026-11-20 旧版规范共用 `#4968ed → #8a6cf1` 蓝紫渐变强调卡与灰蓝大阴影卡片，在 2026-11-25 评审中被明确指出存在“老旧后台 / Bootstrap / 默认 AI 模板感”。

新版统一采用 **「CPAMC v8.1.2 留白精工结构 + 风格 D（秩序精工）色彩与数据叙事体系」**：
- 彻底禁止紫蓝渐变大卡片、禁止厚重弥散阴影、禁止浏览器原生 `alert()` / `confirm()`；
- 在四端之间建立完全一致的视觉语言、排版比例、图表规范和浅交互红线，同时通过顶栏/身份徽章清晰隔离四端权责。

## 3. 排版、圆角与留白纪律

- **字体栈**：
  - 中文无衬线：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Segoe UI", Roboto, sans-serif`
  - 等宽数字/代码/密钥/邮箱：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`，**所有指标数字强制开启 `font-variant-numeric: tabular-nums`**。
- **圆角阶梯**：
  - 主容器卡片（`.cpa-card`）：`16px`
  - 状态 Hero 区域：`24px`（`rounded-3xl`）+ 极淡径向青色网格光晕 `.hero-grid-glow`
  - 输入框 / 嵌套子块：`12px`（`rounded-xl`）
  - 主操作按钮、筛选胶囊、状态徽章：**全胶囊 `9999px`**（`.cpa-pill-btn` / `.cpa-ghost-pill`）
- **阴影**：卡片仅允许极轻阴影 `0 1px 2px rgba(10, 37, 64, 0.03)`；悬停可交互卡片轻浮 `translateY(-2px)` + `0 8px 20px rgba(10, 37, 64, 0.06)`。

## 4. 核心招牌组件规范（吸收 CPAMC v8.1.2）

1. **状态 Hero + 实时波浪卡**：用于学生端「Token 门户」和浣溪平台端「全局总览」——大字状态标题配空心圆环 `○`（绿正常 / 珊瑚红冻结）+ 浮层白卡 + 底部平滑渐变波浪图。
2. **微色条核心 KPI 卡**：每张 KPI 卡顶部配 `24px × 3px` 语义色短横条，中段大号等宽数字，底部配 `3px` 极细进度条或简短对比说明。
3. **章节竖条标题（`.section-eyebrow`）**：左侧 `3px × 26px` 语义色竖胶囊条 + 上行 `11px` 浅灰英文/中文眉标 + 下行 `16px` 粗体标题。
4. **图表 + 可折叠 `数据表`**：所有柱状/趋势图卡片底部统一提供可折叠 `数据表（明细展开）▾`，兼顾宏观可读性与精准查数。
5. **20 格迷你请求健康条**：用于密钥/资源卡内直观呈现最近 20 次调用的成功（翡翠青）与失败（珊瑚红）分布。
6. **点阵分栏登录页**：左侧留白几何点阵画布 + 品牌欢迎语，右侧纯净极简表单（学生端仅保留**所属试点学院 + 教育邮箱 + 验证码**，禁止增加多余学号输入框）。

## 5. 四端信息架构与交互红线

| 端 | 导航壳形态 | 一级板块（严格 ≤ 4 项） | 专属视觉与权限要求 |
| :--- | :--- | :--- | :--- |
| **① 学生端** | 独立点阵登录页 + 顶部 3 导航 | `Token 门户` · `创作中心` · `作品广场` | 创作中心内嵌 CMS 实战课堂与「我的作品」双视角，点课程滑出分步阅读器；右上角提供真实 `退出登录` |
| **② 学院端** | 深海蓝汇报横幅 + 单页四段式（**无侧栏**） | `全局成效总览` → `趋势与活跃` → `本研分层与标杆` → `精选作品墙` | 严格纯只读、零操作按钮、**不使用“教研”字眼**，支持投屏姓名脱敏开关与一键导出汇报摘要 |
| **③ 运营管理端（学校用）** | 左侧 4 菜单（`232px`） | `成员与准入` · `作品管理` · `内容与活动(CMS)` · `激励管理` | 明确标示“仅限本院日常运营”，激励管理采用**机制 A（学院激励池制）**，超池需向浣溪提追加申请 |
| **④ 平台管理端（浣溪内部）** | 左侧 4 菜单（`232px`） | `全局总览` · `学院与账号管理` · `额度策略与审批中心` · `安全审计与防倒卖` | 顶栏与侧栏突出「浣溪公司内部专用」隔离标识；审批与冻结均须二次确认防误点并落审计日志 |

### 通用交互红线
- **核心操作 ≤ 2–3 步触达**，禁止弹窗套抽屉、禁止三级嵌套菜单；
- 所有反馈使用顶部居中胶囊 `Toast`（2.4 秒自动消失），破坏性/资金类操作统一使用规范模态二次确认框；
- 密钥明文仅在重置/首次生成时展示一次，刷新后统一为 `sk-hx******9f4a` 掩码，审计日志严禁落盘密钥明文。
