# 0003 UI 与交互设计规范（V2.0 · ModelScope 创空间全量复刻统一版）

状态：已生效（2026-11-26 全量对齐 `https://modelscope.cn/studios` 视觉与交互规范）  
适用范围：**浣溪AI Lab** 全部四端（① 学生端、② 学院端、③ 运营管理端·学校用、④ 平台管理端·浣溪内部）  
全量参数手册：[modelscope-studios-design-system.md](../modelscope-studios-design-system.md)

---

## 1. 背景与升级目标

为使 **浣溪AI Lab** 具备现代 AI 开发者与高校创客社区的先锋质感，四端原型统一升级为 **ModelScope 魔搭社区「创空间（Studios）」全量 UI 视觉、配色体系、组件解剖结构与微交互动画**：
- 采用 **纯白 `#FFFFFF` 画布 + 冰云软壳 `#F7F9FD` + 宇宙靛蓝 `#27254C` + 电光魔搭紫 `#624AFF` / 极光青 `#36CFD1`** 统一全站视觉；
- 禁止引入 `googleapis` / `gstatic` 等境外阻塞外链，确保国内教育网与公网秒开；
- 完整复刻 **六层极光漫射 Hero、环形星轨热榜轮播、左下反向内凹切角台面、双层主色晕染精选卡、右侧高级筛选抽屉、以及悬停 `-6deg` 微倾的破界外悬缩略图卡片**。

## 3. 四端信息架构与交互红线

| 端 | 导航壳形态 | 一级板块（严格 ≤ 4 项） | 专属视觉与权限要求 |
| :--- | :--- | :--- | :--- |
| **① 学生端** | 独立极光登录页 + `60px` 毛玻璃顶栏 3 导航 | `Token 门户` · `学习与挑战` · `作品广场` | 顶栏右侧统一收敛为单个头像下拉菜单（仅含账号信息、`我的作品` 与 `退出登录`，不放重复外部退出按钮）；全面取消固定双周榜，`学习与挑战` 提供独立 CMS 实战教程与**主题挑战全闭环详情页**（奖项设定、一键带 Tag 参赛、参赛作品流与获奖名单公示）；作品广场呈现星轨热榜、双层晕染精选卡与 `-6deg` 破界卡片 |
| **② 学院端** | 宇宙靛蓝极光汇报横幅 + 单页四段式（无侧栏） | `全局成效总览` → `趋势与活跃` → `本研分层与标杆` → `精选作品墙` | 严格纯只读、零操作按钮、**不使用“教研”字眼**，叠加主题挑战赛拉动节点标注，支持姓名脱敏开关与一键导出汇报摘要 |
| **③ 运营管理端（学校用）** | 左侧冰云软壳 4 菜单 | `成员与准入` · `作品管理` · `教程管理 (CMS)` · `挑战与激励管理` | 仅限本院日常运营；独立拆分 `教程管理 (CMS)`，并在 `挑战与激励管理` 中实行**学院激励池预算预占制**（总获批 = 已实发 + 进行中挑战预占冻结 + 当前可用余量），打通挑战创编冻结、收稿评选、批量定奖结算（实扣并自动释放未用预占回池、同步学生端公示）与志愿者激励；可用池不足需向浣溪提追加申请 |
| **④ 平台管理端（浣溪内部）** | 左侧冰云软壳 4 菜单 | `全局总览` · `学院与账号管理` · `额度策略与审批中心` · `安全审计与防倒卖` | 突出「浣溪公司内部专用」隔离标识；同步监控各院激励池「可用 / 挑战冻结 / 已发」水位，追加审批与秒级冻结均须二次确认并落不可篡改审计日志 |

### 通用交互红线
- **核心操作 ≤ 2–3 步触达**，禁止弹窗套抽屉、禁止原生 `alert()` / `confirm()`；
- 所有反馈使用顶部居中胶囊 `Toast`（2.4 秒自动消失）；
- 密钥明文仅在重置/首次生成时展示一次，刷新后统一为 `sk-hx******9f4a` 掩码，审计日志严禁落盘密钥明文。
