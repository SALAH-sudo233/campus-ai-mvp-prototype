# 0003 UI 规范

状态：已接受
日期：2026-11-20

## 背景

学生端、管理端共用一套视觉。接下来要优化登录界面，还会有其他人改页面。把现有的颜色、间距、组件固定下来，避免各处取值不一致。本规范从当前 `styles.css`、`index.html`、`admin.html` 的实际取值整理而来。

## 决策

### 颜色

颜色统一用 `styles.css` 里 `:root` 的 CSS 变量，不在各处写死色值。

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#17233c` | 主文字 |
| `--muted` | `#71809b` | 次要文字、说明 |
| `--line` | `#e5eaf2` | 边框、分隔线 |
| `--bg` | `#f5f7fb` | 页面背景 |
| `--blue` | `#4968ed` | 主色、主按钮、焦点 |
| `--blue2` | `#667ff5` | 渐变辅助色 |
| `--green` | `#17a673` | 正向金额、有效状态 |

约定取值：错误和吊销用 `#e05c62`；品牌标渐变用 `#536ff1` 到 `#8a6cf1`；强调卡片渐变用 `#506df1` 到 `#7187f3`。新增语义色先在这里登记，再使用。

### 字体与字号

- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif`。等宽（密钥）用 `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。
- 基准 `14px`，行高 `1.5`。
- 登录大标题 `30px`，工作台标题 `28px`，管理台标题 `26px`，卡片数字 `29px`，面板小标题 `17px`，说明 `11px` 到 `13px`。

### 圆角与阴影

- 圆角：输入框和按钮 `9px`，卡片和面板 `15px`，登录卡 `18px`，弹窗 `16px`，徽标 `20px`。
- 阴影统一用低透明度叠加，例如主按钮 `0 5px 13px #4968ed30`，卡片 `0 16px 45px #25345d0d`。不用深重阴影。

### 布局

- 内容区最大宽 `1120px`，管理台 `1000px`，登录卡 `min(100%, 390px)`，居中。
- 工作台内边距 `48px 24px`，顶栏高 `68px`。
- 响应式断点 `max-width: 760px`：多列网格收成单列，隐藏顶栏的用户名。
- 三栏统计卡用 `repeat(3, 1fr)`，主次分栏用 `1fr 340px`。

### 组件

| 组件 | 类名 | 规则 |
|---|---|---|
| 主按钮 | `.primary` | 主色填充，白字，用于页面主操作 |
| 次按钮 | `.outline` | 白底描边，用于次操作 |
| 轻按钮 | `.ghost` | 白底浅边，用于退出、复制 |
| 文字按钮 | `.text-btn` | 无边框，用于重置等弱操作 |
| 危险按钮 | `.danger` | 红字红边，仅用于吊销 |
| 切换标签 | `.tabs` `.tab` | 用于学生/管理员、邮箱/学号切换，选中项加 `.active` |
| 卡片 | `.stat-card` `.panel` | 白底、`--line` 边框、圆角 |
| 状态徽标 | `.badge` | `.active` 绿、`.none`/`.revoked` 红 |
| 轻提示 | `.toast` | 顶部居中，2.4 秒自动消失，用于操作反馈 |
| 弹窗 | `.modal` `.modal-box` | 用于占位功能提示，如充值 |

### 交互

- 操作结果用 `toast()` 反馈，一句话，不弹 `alert`。破坏性操作（吊销）用 `confirm()` 二次确认。
- 焦点态：输入框聚焦加主色边框和 `0 0 0 3px #4968ed17` 外发光。
- 密钥明文只显示一次，复制后仍只在本次可见；刷新后显示掩码。
- 金额正数用 `.plus` 绿色带加号，负数用 `.minus` 红色。
- 数字用 `toLocaleString('zh-CN')` 显示千分位。

### 文案

- 面向学生用“你”，自称“我们”。短句，陈述语气。
- 明确告知边界：密钥只显示一次、原型数据是演示、正式版接官方认证。
- 中英文和数字之间留一个半角空格。

## 后果

- 改样式先改 `:root` 变量和既有类，不新增重复色值和一次性类。
- 登录界面优化在这套变量和组件内做，偏离本规范要先更新这条 ADR。
- 两个页面共用 `styles.css`；管理台特有样式内联在 `admin.html` 的 `<style>` 里，仅限管理台用到的表格和徽标。
