# 校园 AI 创作平台 MVP 原型

这是一个无需构建工具的可运行前端原型，当前所有数据均为演示数据，登录为 Mock 登录。原型用于验证“校园身份登录 → 首次领取额度 → 查看与消耗 Token”的产品流程。

## 运行

在本目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。数据保存在浏览器 `localStorage`，点击页面底部“重置演示数据”可恢复初始状态。

## 已包含

- 校园邮箱 / 学号登录切换（不收集密码）
- 首次一次性赠送 100,000 Token（原型中可在 `app.js` 调整）
- 余额、累计消耗和 Token 流水
- 模拟消耗 Token、充值入口占位、退出登录
- 移动端适配及空状态、余额不足提示

## 生产接入边界

生产环境应由后端对接华中科技大学官方 SSO/CAS。前端只接收经过后端校验的身份结果或短期会话，不创建校园密码输入框，也不保存校园密码。首次赠送必须由服务端按学生唯一身份幂等执行：同一学生无论登录多少次只能生成一笔赠送流水。Token 余额和流水以服务端为准，前端 localStorage 仅用于本演示。

后续可接入作品发布、校方看板、充值支付和 Teams 入口；自动部署与复杂资源隔离不属于本期原型。
